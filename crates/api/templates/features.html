{# ── Capability highlights ────────────────────────────────────────────── #}

Core capabilities

{# Hybrid search #}

Hybrid search

Combines keyword matching (full-text) with semantic vector search using Reciprocal Rank Fusion. Find documents by meaning, not just exact words.

{# Multi-tenant #}

Multi-tenant isolation

Every tenant's data is strictly isolated at the database level with PostgreSQL Row-Level Security. One tenant can never access another's files.

{# Encryption #}

Encryption at rest

Per-tenant encryption keys (AES-256-GCM) for all stored content. Files are encrypted before they touch disk, with keys you control.

{# Export #}

Data export

Export all your data as a streaming ZIP archive (original files + metadata in JSONL). Fully round-trippable — import into another instance.

{# AI tagging #}

AI auto-tagging

Every ingested file gets a descriptive title, summary, and semantic tags from LLM analysis. Tags are canonicalized across your tenant for consistency. Use the knowledge base as a persistent AI memory — ideal for company documentation that's grown too large to navigate, and for giving your AI tooling a queryable long-term memory of decisions, runbooks, and reference material.

{# Flexible deployment #}

Self-hostable

Runs on your own infrastructure with Podman containers. Local LLM backends supported — your files never leave your network unless you choose remote models.
